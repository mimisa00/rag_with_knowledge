🔧 角色權限系統測試報告

📋 測試摘要

測試時間：

測試目標：驗證角色權限儲存和載入功能是否正常運作

🔍 問題診斷

1. 權限表單系統不一致

問題：存在兩套不同的權限系統
  • 靜態 HTML 權限：硬編碼在 HTML 中，使用具體權限名稱作為 name 屬性
  • 動態載入權限：從 API 載入，使用統一的 name="permissions"
// 靜態權限（原始） <input type="checkbox" name="kb_create"> 建立 <input type="checkbox" name="kb_read"> 檢視 // 動態權限（新系統） <input type="checkbox" name="permissions" value="kb.create"> <input type="checkbox" name="permissions" value="kb.read">

2. 權限收集邏輯錯誤

問題：saveRole 函數收集了所有 checkbox，包括非權限項目
// 錯誤的收集方式 form.querySelectorAll('input[type="checkbox"]').forEach(cb => { permissions[cb.name] = cb.checked; // 會收集到 is_active });
結果：儲存到資料庫的是 {"permissions": false}

3. 編輯角色權限載入失敗

問題：editRole 函數使用錯誤的選擇器
// 嘗試用權限名稱作為 name 屬性查找 const checkbox = document.querySelector(`input[name="${key}"]`); // 但實際上 checkbox 的 name 是 "permissions"

✅ 已實施的修正

修正 1：統一使用動態權限系統

變更：移除 HTML 中的靜態權限項目
// organization.html <div class="permission-grid"> <!-- 動態載入權限項目 --> <div class="loading-spinner"> <div class="spinner"></div> <p>載入權限設定中...</p> </div> </div>

修正 2：修正權限收集邏輯

變更：只收集 name="permissions" 的 checkbox
// 修正後的 saveRole 函數 form.querySelectorAll('input[name="permissions"]:checked').forEach(cb => { const permId = cb.value; const perm = window.permissions.find(p => p.id === permId || p.code === permId); if (perm) { permissions[perm.code || permId] = true; } });

修正 3：修正編輯角色的權限載入

變更：使用正確的選擇器並重新載入權限選項
// 修正後的 editRole 函數 // 先載入權限選項 await loadPermissionOptions(); // 根據角色權限勾選對應的 checkbox for (const [permCode, value] of Object.entries(rolePermissions)) { if (value) { const perm = window.permissions.find(p => p.code === permCode || p.id === permCode); if (perm) { const checkbox = document.querySelector(`input[name="permissions"][value="${perm.id}"]`); if (checkbox) { checkbox.checked = true; } } } }

修正 4：確保新增角色時正確初始化

變更：showAddRoleModal 改為 async 並載入權限
async function showAddRoleModal() { // ... 清除表單資料 ... // 載入權限選項 await loadPermissionOptions(); // 清除所有權限的勾選 document.querySelectorAll('input[name="permissions"]').forEach(cb => { cb.checked = false; }); modal.classList.add('show'); }

  2. 測試編輯角色：
