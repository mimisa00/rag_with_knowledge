掃描分析 /frontend/static/ 目錄下的所有 HTML 檔案，建立前端頁面架構索引。

## 分析內容

1. **頁面基本資訊**：
   - 檔案名稱和路徑
   - 頁面標題 (<title> 標籤內容)
   - 檔案大小和行數
   - 頁面主要功能描述

2. **JavaScript 依賴**：
   - 引入的外部 JS 檔案清單 (<script src="">)
   - 內聯 JavaScript 程式碼大小估計
   - 共用元件使用情況

3. **頁面分類**：
   - 管理員頁面 (admin/*)
   - 一般使用者頁面
   - 認證相關頁面 (login, register, activate)
   - 功能複雜度評級 (簡單/中等/複雜)

4. **頁面間關係**：
   - 導航連結和跳轉關係
   - 表單提交目標
   - iframe 或其他嵌入關係

## 輸出格式

請提供結構化的分析報告，包含：

### 1. 頁面清單總覽表格
| 檔案 | 標題 | 類型 | 行數 | 複雜度 | 主要功能 |

### 2. JavaScript 依賴關係圖
- 每個頁面引用的 JS 檔案清單
- 共用元件使用統計

### 3. 頁面分類結果
- 按功能模組分組
- 複雜度評分說明

### 4. 建議深入分析清單
- 標記需要詳細事件綁定分析的重點頁面
- 優先順序排序

## 特別注意
- 重點關注大型檔案 (>500行)
- 識別使用複雜 JavaScript 的頁面
- 記錄可能有 AJAX/Fetch 呼叫的頁面標記
- 不需要分析 JavaScript 程式碼內容，只做結構性掃描

請確實讀取每個 HTML 檔案並提供完整的結構化分析。
