Vertex AI 設定指南

Service Account Key 設定步驟
  1. 建立 Service Account： 
    gcloud iam service-accounts create rag-vertex-ai \
    --display-name="RAG Vertex AI Service Account"
  2. 授予權限： 
    gcloud projects add-iam-policy-binding ${PROJECT_ID} \
    --member="serviceAccount:rag-vertex-ai@${PROJECT_ID}.iam.gserviceaccount.com" \
    --role="roles/aiplatform.user"
  3. 下載 Key： 
    gcloud iam service-accounts keys create ./credentials/vertex-ai-key.json \
    --iam-account=rag-vertex-ai@${PROJECT_ID}.iam.gserviceaccount.com
  4. 重啟服務： 
    docker compose restart backend
重要提醒：
  • 此操作是在宿主機操作，請確認宿主機有安裝 gcloud CLI 並且已登入，且專案有啟用 Vertex AI API
  • 此操作需在專案目錄執行，請確認專案目錄有 credentials 目錄
  • Key 檔案必須放在 ./credentials/vertex-ai-key.json
  • 確保檔案權限：chmod 644 credentials/vertex-ai-key.json
  • 不要將 key 檔案提交到版本控制
  • 建議每 90 天更換一次 key
