🐛 問題 1：新增帳號按鈕錯誤 已修復
問題描述：
點擊「新增帳號」按鈕時出現錯誤：
Uncaught TypeError: Cannot set properties of null (setting 'value')
解決方案：
修正 JavaScript 中的元素 ID 匹配問題：
  • userLoginId → userLoginid
  • userName → userUsername
  • 加入元素存在性檢查
測試步驟：
1 切換到「帳號管理」分頁
2 點擊「新增帳號」按鈕
3 確認模態框正常顯示，無錯誤訊息
4 填寫表單並儲存
🏢 問題 2：編輯部門時無法選擇上級部門 已修復
問題描述：
編輯部門時，「上級部門」下拉選單只有「無（頂層部門）」選項，無法選擇其他部門。
解決方案：
  • 在 editDepartment 函數中加入 loadDepartmentOptions() 呼叫
  • 實作排除邏輯，避免部門選擇自己或子部門作為上級（防止循環引用）
  • 使用 setTimeout 確保選項載入後再設定選中值
測試步驟：
1 在部門列表中選擇一個部門
2 點擊「編輯」按鈕
3 檢查「上級部門」下拉選單是否有其他部門選項
4 確認當前部門和其子部門不在選項中（避免循環引用）
5 選擇新的上級部門並儲存
6 確認部門樹狀結構正確更新
